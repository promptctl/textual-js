# Design System

## Overview

Textual uses a theme-based design system where a `Theme` object maps variable names to colors, and those variables are consumed in CSS. Themes can be swapped at runtime, causing the entire UI to re-render with the new color palette.

## Themes

A theme is an instance of `textual.theme.Theme`. It defines up to 11 base colors and an optional `variables` dictionary for fine-grained overrides.

### Changing the Theme

- At runtime via the Command Palette (Ctrl+P).
- Programmatically by setting `App.theme` to a registered theme name.

```python
self.theme = "nord"
```

### Registering a Custom Theme

Themes must be registered before use. Built-in themes are registered automatically.

```python
from textual.theme import Theme

arctic_theme = Theme(
    name="arctic",
    primary="#88C0D0",
    secondary="#81A1C1",
    accent="#B48EAD",
    foreground="#D8DEE9",
    background="#2E3440",
    success="#A3BE8C",
    warning="#EBCB8B",
    error="#BF616A",
    surface="#3B4252",
    panel="#434C5E",
    dark=True,
    variables={
        "block-cursor-text-style": "none",
        "footer-key-foreground": "#88C0D0",
        "input-selection-background": "#81a1c1 35%",
    },
)
```

Register via `App.register_theme` (typically in `on_mount`), then set `App.theme`.

## Base Colors

Only `$primary` is required. Textual generates defaults for any omitted base colors.

| Variable | Purpose |
|---|---|
| `$primary` | Branding color. Titles, strong-emphasis backgrounds. |
| `$secondary` | Alternative branding color for differentiation from primary. |
| `$foreground` | Default text color. Must be legible on `$background`, `$surface`, and `$panel`. |
| `$background` | Background where there is no content. Default screen background. |
| `$surface` | Default widget background, sits on top of `$background`. |
| `$panel` | Differentiates a UI section from main content. Used sparingly. |
| `$boost` | Color with alpha for creating layered backgrounds. |
| `$warning` | Indicates a warning. Typically a background color. |
| `$error` | Indicates an error. Typically a background color. |
| `$success` | Indicates success. Typically a background color. |
| `$accent` | Draws attention. Typically contrasts with `$primary` and `$secondary`. |

## Shades

For every base color, Textual generates 3 lighter and 3 darker shades:

- Lighter: `{color}-lighten-1`, `{color}-lighten-2`, `{color}-lighten-3` (3 is lightest).
- Darker: `{color}-darken-1`, `{color}-darken-2`, `{color}-darken-3` (3 is darkest).

Example: `$secondary-darken-1`, `$error-lighten-3`.

## Light and Dark Themes

The `dark` argument in the `Theme` constructor declares whether the theme is light or dark. This flag influences how Textual generates derived variables and may affect built-in widget appearance.

## Text Colors

### Default Text

- `$foreground` -- default text color.
- `$foreground-muted` -- lower-importance text.
- `$foreground-disabled` -- disabled/unselectable text.

### Auto-Contrast Text

These variables adapt to the background they appear on:

- `$text` -- slightly transparent black or white, whichever has better contrast against the current background.
- `$text-muted` -- faded version for lower-importance text.
- `$text-disabled` -- faded version for disabled text.

### Colored Text

Derived from base colors, tinted to guarantee legibility against `$background`, `$surface`, and `$panel`:

- `$text-primary`
- `$text-secondary`
- `$text-accent`
- `$text-warning`
- `$text-error`
- `$text-success`

These are also legible against their corresponding muted-color backgrounds.

## Muted Colors

Generated by blending a base color with `$background` at 70% opacity. Designed so that the corresponding `$text-{color}` is legible against the muted background.

- `$primary-muted`
- `$secondary-muted`
- `$accent-muted`
- `$warning-muted`
- `$error-muted`
- `$success-muted`

## Additional Theme Variables

Fine-grained variables used by built-in widgets. All can be overridden via the `variables` dict in the `Theme` constructor. The `variables` dict can also override derived variables such as `$primary-muted` and shade variables.

### Border

| Variable | Default |
|---|---|
| `$border` | `$primary` |
| `$border-blurred` | Slightly darkened `$surface` |

### Cursor (Block)

| Variable | Default |
|---|---|
| `$block-cursor-foreground` | `$text` |
| `$block-cursor-background` | `$primary` |
| `$block-cursor-text-style` | `"bold"` |
| `$block-cursor-blurred-foreground` | `$text` |
| `$block-cursor-blurred-background` | `$primary` at 30% opacity |
| `$block-cursor-blurred-text-style` | `"none"` |
| `$block-hover-background` | `$boost` at 5% opacity |

### Input Cursor

| Variable | Default |
|---|---|
| `$input-cursor-background` | `$foreground` |
| `$input-cursor-foreground` | `$background` |
| `$input-cursor-text-style` | `"none"` |
| `$input-selection-background` | `$primary-lighten-1` at 40% opacity |

### Scrollbar

| Variable | Default |
|---|---|
| `$scrollbar` | `$panel` |
| `$scrollbar-hover` | `$panel-lighten-1` |
| `$scrollbar-active` | `$panel-lighten-2` |
| `$scrollbar-background` | `$background-darken-1` |
| `$scrollbar-corner-color` | `$scrollbar-background` |
| `$scrollbar-background-hover` | `$scrollbar-background` |
| `$scrollbar-background-active` | `$scrollbar-background` |

### Links

| Variable | Default |
|---|---|
| `$link-background` | `"initial"` |
| `$link-background-hover` | `$primary` |
| `$link-color` | `$text` |
| `$link-style` | `"underline"` |
| `$link-color-hover` | `$text` |
| `$link-style-hover` | `"bold not underline"` |

### Footer

| Variable | Default |
|---|---|
| `$footer-foreground` | `$foreground` |
| `$footer-background` | `$panel` |
| `$footer-key-foreground` | `$accent` |
| `$footer-key-background` | `"transparent"` |
| `$footer-description-foreground` | `$foreground` |
| `$footer-description-background` | `"transparent"` |
| `$footer-item-background` | `"transparent"` |

### Button

| Variable | Default |
|---|---|
| `$button-foreground` | `$foreground` |
| `$button-color-foreground` | `$text` |
| `$button-focus-text-style` | `"bold reverse"` |

## App-Specific Variables

Apps can define their own theme variables by overriding `App.get_theme_variable_defaults`. This method returns a dict of variable names to default values. If a theme's `variables` dict also defines a variable, the theme value takes precedence.

## Previewing Colors

```bash
textual colors
```

Launches an interactive preview of all base variables and generated shades. The theme can be changed inside the preview via the Command Palette.
