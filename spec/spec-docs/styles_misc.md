# Style Spec Index (Misc)

This file is an index-only routing spec for style topics that were previously duplicated here.

It intentionally avoids restating property contracts so each property has one canonical spec.

## Canonical Style Specs

| Style Topic | Canonical Spec |
|---|---|
| `background`, `background-tint`, `tint`, `hatch` | `spec/styles_background_tint.md` |
| `keyline` | `spec/styles_keyline.md` |
| `overflow`, `overflow-x`, `overflow-y`, `scrollbar-gutter`, `scrollbar-size`, `scrollbar-visibility` | `spec/styles_overflow.md` |
| `pointer` | `spec/styles_pointer.md` |

## Resolution Rule

When documentation, tooling, or future edits need the behavior contract for one of the topics above, use the canonical spec listed in the table and do not duplicate the contract text in this file.
