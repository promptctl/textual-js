# Help and Support Channels

This spec defines where users should go for support, bug reports, feature requests, and community discussion.

## Support Entry Points

### Bugs and Feature Requests

Use GitHub Issues for:

- Bug reports
- Feature requests

Endpoint:

- `https://github.com/Textualize/textual/issues`

### Usage Questions and How-To Support

Use GitHub Discussions for questions about building apps with Textual.

Endpoint:

- `https://github.com/Textualize/textual/discussions`

### Realtime Community Support

Use the Textual Discord server for realtime chat and community feedback.

Endpoint:

- `https://discord.gg/Enf6Z3qhVr`

## Triage Guidance

- Check the roadmap before opening feature requests to avoid duplicate requests for already-tracked work.
- Use Issues for actionable work items and Discussions for open-ended usage questions.
- Use Discord when fast iterative back-and-forth is needed.
